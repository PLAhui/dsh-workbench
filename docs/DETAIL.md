# 个人工作台

每天三件、暂存区、任务池、周计划复盘，数据沉底。工作台只做视图层，不另存一套数据。

## 用法

从左栏「个人工作台」进入。

- **今日聚焦**：一天最多三件。加第四件时会标红提示，但不拦你——周末复盘会拿着账本找你。
- **暂存区**：想到就记，输入时不分类。每条可以标四象限，每天集中分流一次，转成任务或移到明天。
- **任务池**：列表 / 看板 / 日历三种看法，同一份数据。
- **周计划 · 复盘**：周初定三件，周末对照收口；顺延次数会自动汇总进来。
- **数据源**：MNEMON 记忆与文档、DSH 会话，都是只读。

改动自动保存在浏览器本机，不需要点保存。「清空」会连示例数据一起清掉。

## 数据从哪来

插件跑在 DSH 的 Host 进程里，直接读本机文件，不起外部服务、不联网：

- MNEMON：`~/.mnemon/runtime/memories.json` 与 `~/.mnemon/documents/index.json`。
- DSH 会话：`~/.dsh/sessions/` 下近 7 天的会话，按工作区聚合。

## 边界

- 所有数据源都是只读，工作台不回写 MNEMON 或会话。
- 读不到文件时对应卡片显示「未读取」，其余功能不受影响。
